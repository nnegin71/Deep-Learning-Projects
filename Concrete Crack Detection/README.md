# Concrete Crack Detection
Using Convolutional Neural Network (ConvNet) to develop a classifier for detecting crack in concrete images

Goal:

Building a ConvNet to determine whether there is a crack in any of the concrete images. 


Steps:

1. Explore data and label them
2. Data Loading and Preprocessing
2. Creating the ConvNet Model with PyTorch
3. Model Training and Evaluation
4. Explore using preTrained model (ResNet18) for this task
