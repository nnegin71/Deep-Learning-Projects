# Environmental Sound Classification
Using Audio analysis and Convolutional Neural Network (CNN) to classify environmental sounds to 10 classes

This project is one of the Kaggle competition projects, where audio processing, audio feature extraction, audio analysis, and some deep learning concepts such as train-test data split, multi-class classification, and convolutional NN are explored.
TensorFlow platform is used to develope the CNN model and evaluate its performance using accuracy metric. 

**Goal:**
Determine environment sound class

**Data Source:**
https://www.kaggle.com
